# Changes

## 0.2.0 — Public beta

- Windows, macOS and Linux platform helpers and packaging.
- English/Turkish, onboarding, app help and light/dark/system appearance.
- Encrypted multiple profiles, safe session-only fallback, WireGuard drag/drop and localhost SOCKS5.
- Application discovery, custom paths, presets and named selections.
- Tunnel, encrypted DNS and smart direct/DNS detection.
- Real selected-outbound HTTP checks, truthful Discord/UDP status and explicit failure policies.
- Tray/menu-bar controls, opt-in startup behavior, network/wake recovery checks, quiet error handling.
- Redacted support export, pinned-key signed release manifests, verified manual installer download and stable/beta channels.
- Public download page, source distribution and platform CI including real TUN session lifecycle and packaged UI checks.

## 0.1.0 — Initial private Mac beta

- Single-peer WireGuard import, Discord presets and a macOS TUN helper.
- Local connection viewer and initial visual Turkish setup guide.
